# 시험용 샌드박스 템플릿

응시자가 시험 중 코드를 돌리는 환경입니다. `_shared/sandbox.ts` 가 이 템플릿을
띄웁니다.

## 왜 커스텀 이미지가 필요한가

응시 중 샌드박스의 **외부 송신은 기본 차단**입니다. 샌드박스가 열린 인터넷으로
나갈 수 있으면 전체화면 감독·탭 전환 감지를 전부 우회하는 부정행위 통로가 되기
때문입니다. 그래서 응시자가 쓸 패키지와 폰트는 미리 이미지에 넣어야 합니다.

## 빌드

로컬에서 한 번만 하면 됩니다(E2B 계정 필요).

```bash
npm i -g @e2b/cli
e2b auth login
cd supabase/e2b
e2b template build -c "/root/.jupyter/start-up.sh" --name hrd-exam
```

출력된 템플릿 ID 를 Supabase 엣지 함수 시크릿에 넣습니다.

| 시크릿 | 값 | 없을 때 동작 |
|---|---|---|
| `E2B_API_KEY` | E2B API 키 | 에이전트가 동작하지 않음 |
| `E2B_TEMPLATE` | 위에서 받은 템플릿 ID | 기본 `base` 이미지 사용 — 한글 폰트·pandas 없음 |
| `SANDBOX_ALLOW_OUT` | 비워 둠 | 비우면 외부 송신 전면 차단(권장) |

`SANDBOX_ALLOW_OUT` 는 쉼표로 호스트·IP·CIDR 을 적으면 그것만 열립니다. 시험
환경에서는 비워 두는 것이 기본값입니다. 도메인 매칭은 HTTP(:80) 의 Host 헤더와
TLS(:443) 의 SNI 로 동작하므로, 다른 포트를 열려면 IP·CIDR 로 적어야 합니다.

## 버전을 고정하는 이유

`pip install` 에 버전을 못박아 두었습니다. 회차마다 라이브러리가 달라지면 같은
답안이 회차에 따라 다르게 채점됩니다. 그건 평가가 아닙니다. 패키지를 올릴 때는
템플릿을 새로 빌드하고 시행 중인 회차가 없는 시점에 교체합니다.

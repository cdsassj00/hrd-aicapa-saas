# E2E 테스트

운영 Supabase 를 그대로 쓴다. 스테이징이 없기 때문이다. 따라서

- **쓰기를 만드는 테스트는 전용 계정으로만** 한다(`E2E_EMAIL`/`E2E_PASSWORD`).
- 조직·회차·문항을 새로 만들지 않는다. 이미 있는 것만 읽는다.
- 가입 플로우는 **접수 직전까지만** 확인한다. 실제 제출은 운영 문의 테이블을
  더럽히므로 버튼 활성/비활성과 검증 메시지까지만 본다.

실행:

    E2E_BASE_URL=http://127.0.0.1:8080 \
    E2E_EMAIL=... E2E_PASSWORD=... \
    npx playwright test
